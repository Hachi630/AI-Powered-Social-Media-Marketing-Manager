# 扩展文件上传功能支持文档类型

## 目标

扩展聊天框的文件上传功能，支持上传PDF、Word、PPT、Excel、TXT等文档类型，并支持拖拽上传。文件显示为图标和文件名，文件大小限制50MB。

## 实现步骤

### 1. 后端：添加通用文件上传端点

**文件**: `backend/src/routes/upload.ts`

- 创建新的上传目录 `uploads/files`（与 `uploads/images` 分开）
- 添加新的multer配置，支持多种文件类型：
- PDF: `application/pdf`
- Word: `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
- PPT: `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.presentationml.presentation`
- Excel: `application/vnd.ms-excel`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- TXT: `text/plain`
- 其他常见文档类型
- 文件大小限制：50MB
- 添加新的路由 `/api/upload/file` 用于上传通用文件
- 返回文件URL和文件信息（文件名、类型、大小）

### 2. 前端：扩展uploadService

**文件**: `frontend/src/services/uploadService.ts`

- 添加 `UploadFileResponse` 接口，包含 `fileUrl`, `fileName`, `fileType`, `fileSize`
- 添加 `uploadFile` 方法，用于上传通用文件
- 支持与图片上传相同的认证机制

### 3. 修改ChatBox组件数据结构

**文件**: `frontend/src/components/ChatBox.tsx`

- 添加新的状态管理：
- `uploadedFiles: Array<{url: string, name: string, type: string, size: number}>` - 存储已上传的文件
- 修改现有的 `uploadedImages` 逻辑，区分图片和文件
- 或者统一使用 `uploadedAttachments` 包含图片和文件

### 4. 更新文件验证逻辑

**文件**: `frontend/src/components/ChatBox.tsx`

- 修改 `validateFile` 函数，支持图片和文档文件
- 图片文件：JPG, PNG, GIF, WEBP（10MB限制）
- 文档文件：PDF, Word, PPT, Excel, TXT等（50MB限制）
- 根据文件类型应用不同的限制

### 5. 实现文件上传处理

**文件**: `frontend/src/components/ChatBox.tsx`

- 修改 `handleFileUpload` 函数：
- 检测文件类型（图片 vs 文档）
- 图片使用 `uploadService.uploadImage`
- 文档使用 `uploadService.uploadFile`
- 分别存储到 `uploadedImages` 和 `uploadedFiles`
- 更新上传限制：图片最多5张，文件最多5个（或总共10个附件）

### 6. 实现文件预览组件

**文件**: `frontend/src/components/ChatBox.tsx` 和 `frontend/src/components/ChatBox.module.css`

- 在图片预览区域下方添加文件预览区域
- 显示文件图标（根据文件类型使用不同的图标）
- 显示文件名和文件大小
- 每个文件有删除按钮
- 使用Ant Design的图标：
- `FilePdfOutlined` - PDF
- `FileWordOutlined` - Word
- `FilePptOutlined` - PPT
- `FileExcelOutlined` - Excel
- `FileTextOutlined` - TXT/其他

### 7. 更新消息发送逻辑

**文件**: `frontend/src/components/ChatBox.tsx` 和 `frontend/src/services/chatService.ts`

- 修改 `handleSend` 函数，同时发送图片和文件
- 更新 `chatService.sendMessage`，添加 `files` 参数
- 更新 `ChatMessage` 接口，添加 `files` 字段

### 8. 更新后端消息存储

**文件**: `backend/src/routes/chat.ts` 和 `backend/src/models/Conversation.ts`

- 修改消息模型，添加 `files` 字段（数组）
- 更新聊天路由，支持接收和存储文件信息
- 文件信息包含：URL、文件名、类型、大小

### 9. 更新消息显示逻辑

**文件**: `frontend/src/components/ChatBox.tsx`

- 在消息显示区域，同时显示图片和文件
- 文件显示为可点击的链接或卡片
- 点击文件可以下载或在新窗口打开

### 10. 更新文件输入accept属性

**文件**: `frontend/src/components/ChatBox.tsx`

- 修改文件输入框的 `accept` 属性，包含所有支持的文件类型
- 或者使用两个输入框：一个用于图片，一个用于文件（可选）

## 技术细节

### 支持的文件类型

- **图片**: image/jpeg, image/jpg, image/png, image/gif, image/webp
- **PDF**: application/pdf
- **Word**: application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document
- **PPT**: application/vnd.ms-powerpoint, application/vnd.openxmlformats-officedocument.presentationml.presentation
- **Excel**: application/vnd.ms-excel, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
- **TXT**: text/plain
- **其他**: 可以根据需要扩展

### 文件大小限制

- 图片：10MB
- 文档：50MB

### 文件存储

- 图片：`backend/uploads/images/`
- 文件：`backend/uploads/files/`

### 用户体验

- 拖拽区域同时支持图片和文件
- 文件预览显示图标、文件名和大小
- 可以删除已上传的文件
- 发送消息时包含所有附件
